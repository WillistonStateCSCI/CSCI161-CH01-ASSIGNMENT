```
METHOD reverseArray(numbers)

    SET left = 0
    SET right = length of numbers - 1

    WHILE left < right

        SET temp = numbers[left]
        numbers[left] = numbers[right]
        numbers[right] = temp

        left = left + 1
        right = right - 1

    END WHILE

END METHOD
```
